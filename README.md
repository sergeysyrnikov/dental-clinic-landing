# Белая Линия — шапка и первый экран

Тестовое задание на вакансию графического дизайнера: шапка и первый экран сайта
стоматологической клиники. Собирается в **Tilda** (платный тариф), без Figma —
макеты под три разрешения руками не рисуем.

## Идея

Спокойная стоматология для взрослых и детей. Главная эмоция — «здесь не страшно
и не разведут на деньги»: понятный план лечения, фиксированная смета, врач,
который объясняет каждый шаг.

## Объём

- Шапка: лого, меню, телефон, кнопка записи, бургер на мобильном.
- Первый экран: заголовок, подзаголовок, два CTA, строка доверия, фото,
  карточка с формой записи.

Остальные секции и страницы в задание не входят.

## Структура репозитория

```
docs/
  brief.md           позиционирование, аудитория, тон, состав экрана
  copy.md            все тексты, включая запасные варианты H1
  design-system.md   палитра, типографика, сетка, состояния, брейкпоинты
assets/              фото, лого, иконки, OG-картинка (появится в работе)
```

Документы в `docs/` — источник правды. Тексты, цвета и размеры меняются сначала
там, потом в Tilda.

## Сборка

| Элемент | Инструмент | Адаптив |
|---|---|---|
| Шапка | стандартный блок с меню | автоматически |
| Первый экран | Zero Block, артборды Desktop + Mobile | mobile вручную, tablet точечным CSS |
| Карточка с формой | стандартный блок формы | автоматически |
| Типографика и кнопки | настройки Tilda + один CSS-слой в HEAD | 1200 / 960 / 640 / 480 |

Готовые шаблоны Tilda не используем. Кастомный CSS — только там, где настройки
не дают результата: hover-переходы, тени, вид полей формы.

## План

1. Ассеты: фото, лого, иконки, OG-превью.
2. CSS-слой: переменные палитры, кнопки, поля, карточка.
3. Проект в Tilda на пустом шаблоне, настройки страницы.
4. Шапка → первый экран (desktop).
5. Мобильный артборд, правка планшета.
6. Полировка, SEO и OG, публикация.
7. Сдача: ссылка, скриншоты 1440 и 390, описание концепции.
